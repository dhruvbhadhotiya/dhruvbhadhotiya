## README contract (automation agent + game agent)
`README.md` is generated by `scripts/generate-readme.mjs`. It must contain marker blocks:

- `<!-- BEGIN:ttt --> ... <!-- END:ttt -->` — exact content returned by
  `game/engine.mjs`'s `renderSection(state, repo)`. The game agent owns this function's output shape.
- `<!-- BEGIN:activity --> ... <!-- END:activity -->` — activity bullet list from `data/profile.json`.
- `<!-- BEGIN:live --> ... <!-- END:live -->` — the three live stat cards.

`game/engine.mjs` MUST export exactly: `newGame`, `winner`, `aiMove`, `play`, `renderSection`.
`renderSection(state, repo)` returns HTML that references tiles as:
`assets/ttt/<kind>-light.svg` and raw URL
`https://raw.githubusercontent.com/<repo>/main/assets/ttt/<kind>-dark.svg`
where `<kind>` is one of `empty`, `x`, `o`, `x-win`, `o-win`.

`game/play.mjs` must read title/player from env, apply move via `play()`, write `data/ttt.json`,
replace ONLY the `<!-- BEGIN:ttt -->...<!-- END:ttt -->` block in README, and write a reply markdown
file to `$REPLY_FILE`. Issue titles: `ttt|move|<0-8>` or `ttt|new`.

## Workflows
- `.github/workflows/tic-tac-toe.yml`: on `issues: [opened]`, `if: startsWith(title,'ttt|')`,
  least-privilege permissions, concurrency group, untrusted fields only via `env`, commit with bot,
  retry push, comment + close issue with `if: always()`.
- `.github/workflows/refresh-profile.yml`: `schedule` (daily) + `workflow_dispatch`;
  runs `node scripts/fetch-stats.mjs`, `node scripts/generate-assets.mjs`,
  `node scripts/generate-readme.mjs`, commits changes if any.

## Quality bar
- No external npm dependencies. Node 20 ESM (`.mjs`).
- Deterministic, idempotent generators (safe to re-run).
- Escape any data interpolated into SVG/HTML.
- Clear code comments at the top of each script explaining purpose and inputs/outputs.
